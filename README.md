# kshulab
An interactive chaos simulator exploring particle systems, chaotic motion, and Mandelbrot fractals with live controls and PNG export.
MOKU-SHU is an interactive chaos simulator built using HTML, CSS, JavaScript and Canvas.
It lets users explore particle motion and mathematical fractal patterns through a simple interactive interface.
FeaturesInteractive particle simulation
Mandelbrot fractal visualization
Adjustable speed, chaos, particle count and size
Fractal zoom and iteration controls
Multiple colour modes
Export simulations as PNG images
Tech Stack
HTML ,CSS,JavaScript

HTML Canvas

How to Run

Clone or download this repository.

Open index.html in your browser.

Experiment with the simulation controls.
